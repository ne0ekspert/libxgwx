## ST/IL CPU conversion

The guarded CPU selector supports XGI-CPUU, CPUH, CPUS, CPUE, CPUU/D and CPUUN
for workspaces containing only supported SFC/ST/IEC IL programs, captured default
parameters, one configuration and empty I/O tables. Source, GUIDs and local
variable declarations are preserved. Captured new-file defaults are accepted;
custom parameters, unsupported program metadata, configured modules and other
families require a separate migration and are rejected atomically.

Generate conversion candidates with:

```sh
cargo run --features write,il --manifest-path dev-tools/Cargo.toml --bin text-cpu-acceptance
```

`cpu/{cpue,cpus,cpuh,cpuu,cpuud,cpuun}-{generated,native}.xgwx`
record XG5000 strict syntax/type checks and Save As on 2026-10-10: each had
**0 errors, 0 warnings, 25 messages** for all four ST/IL programs. Tests compare
complete parsed source/declaration semantics and convert the native saves back
to CPUE. Screenshot evidence is under `cpu/`. This is offline editor acceptance;
there was no PLC transfer or execution.

## XGK-CPUSN IL instruction audit

The [LS XGK/XGB instruction manual, chapter 4](https://www.ls-electric.com/upload/customer/download/1375/XGK_XGB_Instruction_English_Manual_V2.0.pdf)
uses `LOAD`, `LOAD NOT`, `AND NOT`, `OR NOT`, `LOADP`, `LOADN`, `OUT`, `OUTP`,
`OUTN`, `SET` and `RST`. These belong to the XGK ladder/IL dialect. The existing
XGK ladder exporter retains those spellings; `cpu/xgk-il-generated.xgwx` and
`cpu/xgk-il.txt` provide a focused regression for LOAD, AND NOT, OUT, LOADP,
OUTP, LOADN, RST and SET. This probe is generated and checked against documented
mnemonics; it is not a native compiler or PLC acceptance fixture.

XGI standalone `Kind=9` programs use IEC IL (`LD`, `LDN`, `ST`, `STN`, `S`, `R`,
`ANDN`, `ORN`). XGK `ANDN` denotes a falling-edge contact, whereas IEC IL `ANDN`
negates AND. The extension diagnoses recognizable XGK mnemonics pasted into
IEC IL source and does not silently translate them. CPU conversion changes
XGI models while preserving source; cross-family language translation is not
part of this operation.
